# Run Empirical Bayes procedure on linear mixed models

Run Empirical Bayes procedure on linear mixed models

## Usage

``` r
rebelEmpBayes(RebelFitObj)
```

## Arguments

- RebelFitObj:

  Object created by running rebelLMM

## Value

A
[`RebelFit-class`](https://ewynn610.github.io/REBEL/reference/RebelFit-class.md)` object`.
